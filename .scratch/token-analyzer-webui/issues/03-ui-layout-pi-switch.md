### 汇总卡片（单组指标卡片）

- 一张卡片一个指标：**请求数 / 输入 / 输出(含推理) / 缓存(cacheRead+cacheWrite) / 推理 / 缓存率 / 总 token / 花费**（8 张）
- 大数字 + 小标签；数值格式化（k/M 缩写或千分位，spec 定：≥10⁴ 用 k/M 缩写，与参考页一致）
- 花费全 0 → 卡片值显示「费率未配置（免费/未定价）」标注（沿用 CLI 的展示口径）
- 卡片数据源：`GET /api/totals`（当前筛选范围）

### 分组表（总览 tab 内）

- 切换「按模型 / 按 cwd」两种分组（参考页是单「按 Provider」表）
- 列：分组键（模型名或规范化 cwd）/ 请求数 / 输入 / 输出 / 缓存率 / 总 token / 花费
- 数据源：`GET /api/groups?by=model|cwd`（带当前筛选）

### 明细表（分 tab + 分页排序）

- **会话明细 tab**：列 = 会话ID / 时间 / cwd / 模型 / 请求数 / 输入 / 输出 / 缓存率 / 总token / 花费；数据源 `/api/sessions`
- **请求明细 tab**：列 = 会话ID / 时间 / 模型 / 输入 / 输出 / 缓存 / 推理 / 缓存率 / 总token / 花费；默认按时间**倒序**；数据源 `/api/requests`
- 每表分页下拉（20 / 50 / 100 行），点击列头排序（升降序切换）

### 时间范围控件（预设 + 自定义按钮组）

- 按钮组：**今天 / 7天 / 30天 / 全部 / 自定义**（默认「全部」）
- 「自定义」展开两个 `datetime-local` 输入（since / until），确定后生效
- 映射为 `/api` 的 `since`/`until` 查询参数（闭区间，复用 CLI 语义）
- 预设按钮换算：今天=当日 00:00 起；7天/30天=当前时刻往前 N 天

### 自动刷新（占位，细节归 ticket 04）

- 顶部「自动刷新 ▾」下拉（Off/5s/30s/5min）+ 手动「刷新」按钮（布局位置同参考页）
- 本 ticket 只定布局；机制决策见 ticket 04

### 导出

- 总览 tab 内「导出 JSON / 导出 CSV」按钮，导出**当前筛选范围**的全量数据
- 由前端 fetch 对应端点后触发浏览器下载（`/api/totals`、`/api/sessions`、`/api/requests` 数据组装为文件），不引入服务端下载端点

### 视觉

- 深色主题（仿参考页 zinc 暗色系），零依赖纯手写 CSS
- 顶部标题 + 数据目录/会话数/数据范围状态行（数据源 `/api/meta`）
- 无框架、无构建（延续项目零依赖约束）
