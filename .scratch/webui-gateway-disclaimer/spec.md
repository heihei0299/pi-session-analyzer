# Spec: webui 统计口径差异展示

Status: ready-for-agent
Type: task

## 背景

2026-08-07 用户报告：pi-switch 网关后台显示「今日」$1.25，token-analyzer webui 显示约 $1.00。逐条对账确认：

- 两侧对同一请求的定价**完全一致**（679 条匹配，0 条不一致）；
- 差异全部来自**覆盖结构**，非计算错误：
  1. pi 压缩/摘要等**内部请求**（无会话名、真实计费）不入 session 对话流（compaction entry 无 usage 字段）→ token-analyzer 结构性漏算（约 $0.10/天）；
  2. **opencode 等其他客户端**请求只在网关日志（dreamer 后台任务等，约 $0.09/天）→ token-analyzer 不覆盖（ADR-0002/#49 已决策结构性接受）。

## 用户决策（2026-08-07）

- **结构性接受这些差异**：不消除、不引入网关日志作为数据源（保持「数据只来自 session 目录」约束）；
- **webui 添加展示**：在界面上向用户说明统计口径与网关的差异，避免再次误判「统计错了」。

## 需求

1. webui 页面（状态行下方）添加**常驻口径说明**（静态文案，不读网关、不动态计算差异金额）：
   - 说明统计仅含 pi 会话对话请求（assistant+usage）；
   - 说明 pi 压缩/摘要等内部请求、opencode 等其他客户端请求**不计入**，与 pi-switch 网关数字存在结构性差异（预期行为）；
   - 文案用中文，与现有 UI 风格一致（dim 小字）。
2. 不改变任何统计逻辑与数据源；不影响现有筛选/预设/导出行为。
3. 08-overview-ui.test.ts 增加骨架断言（说明元素存在、文案关键句）。

## 验收

- [ ] 页面加载后可见口径说明（位置：状态行下方）；
- [ ] 文案覆盖：对话请求口径、内部请求不计入、其他客户端不计入、差异为预期行为；
- [ ] 现有测试全绿；08-overview-ui 新增断言通过；
- [ ] agent_browser 真实浏览器验证可见性（含默认「自 8/1」预设状态）。
