# 03 — 分组键转义

**What to build:** 总览分组表的分组键列（模型名 / cwd 路径）与其他动态字符串同样经过 HTML 转义渲染，含 `&`、`<`、`>`、引号等字符的数据正确显示原文，不再被当作 HTML 解析。消除 webui 全页唯一的注入点。明细表与会话管理已有转义保持原样，不产生双重转义。

**Blocked by:** None — can start immediately

**Status:** resolved

- [x] 分组键含 `&`/`<`/`>`/`"`/`'` 时页面显示原文（源码为转义实体）
- [x] 明细表/会话管理列不出现双重转义（`&amp;lt;` 类）
- [x] 正常分组键（无特殊字符）显示不变

## 实施说明

- `renderTable` 针对无指定格式化函数（`fmts[c.key]` 为空）的列（包括总览分组表的 `key` 列）统一调用 `escapeHtml(v??"")`，特殊字符 `&`、`<`、`>`、`"`、`'` 均被转义为 HTML 实体，页面安全渲染原文。
- 明细表与会话管理已有格式化及单层 `escapeHtml`，无重复转义。
- 自动化测试见 `test/42-webui-fixes-03-07.test.ts`。
